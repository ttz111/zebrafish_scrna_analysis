# Zebrafish Mucosal Immunity Single-Cell Transcriptomic Analysis Pipeline

[![R Version](https://img.shields.io/badge/R-v4.4.3-blue.svg)](https://www.r-project.org/)
[![Seurat](https://img.shields.io/badge/Seurat-v5.5.1-green.svg)](https://satijalab.org/seurat/)
[![CellChat](https://img.shields.io/badge/CellChat-v1.6.1-orange.svg)](https://github.com/sqjin/CellChat)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

This repository provides a modular, reproducible R-based bioinformatics pipeline for processing, integrating, and analyzing single-cell RNA sequencing (scRNA-seq) data. The workflow investigates mucosal immunity, subpopulation heterogeneity, and cell-cell communication dynamics in zebrafish models under Control vs. Infected conditions (`C_group` vs. `E_group`).

---

## 📊 Data Availability & Input Files

* **Raw Data (GEO):** The raw sequencing matrices generated in this study are deposited in the NCBI Gene Expression Omnibus under accession number **GSE342902**.
* **Intermediate Input Files:** 
  * `05_B_cell.R` reads `B_cells_clustered.rds`, which represents the pre-clustered B cell subset derived from the main integrated dataset (`combined_final.rds`). Ensure all necessary subset `.rds` files are placed in your working directories as indicated in the script headers before execution.

## 💻 Software Environment & Compatibility Notes

### Primary Environment
Verified via `sessionInfo()` (see `sessionInfo.txt` in this repository):
* **OS:** Ubuntu 22.04.5 LTS (x86_64-pc-linux-gnu)
* **R Version:** 4.4.3 (2025-02-28)
* **Core Packages:**
  * `Seurat` (v5.5.1) — Quality control, data integration, and marker identification.
  * `harmony` (v1.x) — Independent batch effect correction across biological replicates (`RunHarmony`).
  * `CellChat` (v1.6.1) — Intercellular communication network inference.
  * `clusterProfiler` & `org.Dr.eg.db` — Pathway enrichment for *Danio rerio* (`dre`).
  * `ggplot2` & `dplyr` — Data visualization and manipulation.

> ⚠️ **CRITICAL: Monocle2 Compatibility Warning**
> Monocle2 (v2.x) cannot be executed directly within an R 4.4.3 + Seurat v5 environment due to underlying sparse matrix layout changes and dependency updates. To run pseudotime trajectory analyses (`02_T_cell_analysis.R`, `03_CD4_T_cell.R`, `04_CD8_T_cell.R`, and `05_B_cell.R`), you **MUST** either:
> 1. Use an isolated environment with **R 4.1.x + Seurat v4.x + Monocle2**, OR
> 2. Migrate trajectory code blocks to **Monocle3**.

## 📁 Repository Structure & Workflow

The analysis is organized into six sequential, modular R scripts:

```text
├── .gitignore                     # Git exclusion rules for large datasets and outputs
├── LICENSE                        # Open-source MIT License
├── README.md                      # Repository documentation
├── sessionInfo.txt                # Full environment details generated by sessionInfo()
├── 01_QC_and_Integration.R        # Preprocessing, QC filtering, merging, and Harmony batch correction
├── 02_T_cell_analysis.R           # T cell subclustering, annotation, trajectory, and KEGG enrichment
├── 03_CD4_T_cell.R                # CD4+ T cell cleaning, subclustering, and state transition analysis
├── 04_CD8_T_cell.R                # CD8+ T cell subsetting, proportional dynamics, and DEGs
├── 05_B_cell.R                    # B cell subclustering, marker profiling, and trajectory
└── 06_CellChat.R                  # Ligand-receptor interaction network modeling among immune cell subsets
```
## 🚀 Usage Guide

### 1. Prerequisites & Environment Setup
Ensure that R (>= 4.4.3) is installed along with all required dependency packages. 

> ⚠️ **CRITICAL: Monocle2 Compatibility Notice**  
> `Monocle2` (v2.x) cannot be executed directly within an R 4.4.3 + Seurat v5 environment due to underlying sparse matrix layout changes (`Matrix` v1.7+) and dependency conflicts. To reproduce pseudotime trajectory analyses in scripts `02`, `03`, `04`, and `05`, you **MUST** either:
> 1. Use an isolated conda/container environment with **R 4.1.x + Seurat v4.x + Monocle2**, OR
> 2. Convert trajectory blocks to **Monocle3**.

1. Clone this repository to your local workspace.
2. Ensure all dependent R libraries are installed.
3. Update the local directory paths (`setwd()` or data input paths) within each `.R` script to match your local environment.
4. Execute the scripts sequentially from `01` to `06` to reproduce the analytical results and figures.
